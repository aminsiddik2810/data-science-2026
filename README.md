# Ringkasan Pembelajaran Pertemuan 1–7

### Pertemuan 1
Mempelajari dasar-dasar Python seperti variabel, tipe data, operator, list, dictionary, perulangan, fungsi, dan pengenalan library Data Science.

### Pertemuan 2
Mempelajari penggunaan Pandas untuk membuat dan mengelola DataFrame, melakukan seleksi data, filtering, grouping, dan visualisasi sederhana.

### Pertemuan 3
Mempelajari proses Data Cleaning seperti menangani missing value, menghapus duplikasi, normalisasi data, serta deteksi dan penanganan outlier.

### Pertemuan 4
Mempelajari statistik deskriptif, distribusi data, korelasi, dan visualisasi menggunakan dataset Iris.

### Pertemuan 5
Mempelajari data preprocessing, encoding, normalisasi data, pembagian data latih dan data uji, serta feature engineering.

### Pertemuan 6
Mempelajari konsep dasar Machine Learning menggunakan algoritma klasifikasi seperti Decision Tree dan K-Nearest Neighbors (KNN).

### Pertemuan 7
Mempelajari evaluasi model Machine Learning menggunakan Accuracy, Classification Report, Confusion Matrix, Random Forest, serta prediksi data baru.
