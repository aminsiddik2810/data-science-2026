## Ringkasan Pembelajaran

Pada rangkaian awal perkuliahan, saya mempelajari dasar Python, Pandas, proses pembersihan data, exploratory data analysis, statistik deskriptif, visualisasi, preprocessing, feature engineering, pengenalan machine learning, dan evaluasi model.

Pada Pertemuan 9, saya mempelajari klasifikasi menggunakan **Logistic Regression** dan **Decision Tree** serta mengevaluasi model menggunakan **Confusion Matrix, Accuracy, Precision, Recall, dan F1-Score**. Pada Pertemuan 10, materi berlanjut ke **Random Forest**, konsep ensemble, customer churn, serta penanganan dataset tidak seimbang. Dalam kasus churn, evaluasi tidak cukup hanya menggunakan accuracy karena performa kelas minoritas perlu diperhatikan melalui recall, precision, F1-Score, dan confusion matrix.

Pada Pertemuan 11, saya mempelajari **K-Means**, **Hierarchical Clustering**, dendrogram, Elbow Method, dan Silhouette Score untuk pengelompokan data tanpa label. Pertemuan 12 membahas **Apriori**, frequent itemset, association rules, Market Basket Analysis, serta konsep sistem rekomendasi sederhana. Pertemuan 13 memperkenalkan **Artificial Neural Network** untuk pola non-linear dan pengolahan teks menggunakan **TF-IDF** untuk analisis sentimen.

Secara keseluruhan, rangkaian pembelajaran ini membantu saya memahami alur Data Science mulai dari menyiapkan dan memahami data, membangun model, mengevaluasi hasil, menemukan pola tanpa label, sampai mengenal deep learning dan NLP dasar. Keterbatasan utama dari beberapa praktikum adalah penggunaan dataset contoh atau sintetis, sehingga pengembangan selanjutnya dapat menggunakan dataset dunia nyata, melakukan tuning model, dan membandingkan metode yang lebih beragam.

## Cara Menjalankan Notebook

1. Buka notebook yang diinginkan dari repository GitHub.
2. Buka notebook menggunakan Google Colab.
3. Pilih \*\*Runtime → Restart session and run all\*\* atau \*\*Run all\*\*.
4. Pastikan seluruh sel selesai tanpa error dan semua output tampil.
5. Simpan notebook setelah seluruh proses berhasil dijalankan.
